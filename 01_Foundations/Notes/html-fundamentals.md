# HTML Fundamentals

## What is HTML?

HTML stands for HyperText Markup Language.

HTML provides the structure and meaning of content on a webpage.

## HTML, CSS and JavaScript

HTML = Structure
CSS = Presentation
JavaScript = Behaviour

## Basic HTML element

<tag>Content</tag>

Example:

<p>Hello World</p>

## HTML document structure

<!DOCTYPE html>
<html>
<head>
    <title>Page Title</title>
</head>
<body>

</body>
</html>
