1. Git is a distributed version control system that tracks changes in source code during software development.
2. GitHub is a cloud based platform for developers to store and manage their code securely and efficiently.
3. A working directory is the place where files are checked out and also the folder in my computer where I see and edit actual project whereas Staging holds the exact changes marked for the next commit. It is the preparation area telling Git I want to include this in my next commit.
4. git add moves new and modified files from my working directory into staging area
5. git commit saves a snapshot of my staged changes to my local repository history
6. git push uploads my local repository commits to a remote repository.
7. git status displays the current state of my Git repository by comparing my working directory, staging area and latest commit
8. git diff shows me the exact line by line difference between various states of my repository.
9. I would use git branch to isolate code change and work on a new feature or experiment without affecting the main.
10. .gitignore file tells Git which files and folders to intentionally ignore so they are not tracked, staged or commited.
11. git merge is the core operation used to combine the commit history and changes from one branch to another.
12. the workflow shows the command for when a file is added (git add) to the from the working directory to the staging area and then a snapshot of the changes is then saved to my repository (git commit) and then it is uploaded to my remote repository (GitHub) with git push
